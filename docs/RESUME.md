## Three polished resume bullets

* **Shipped GeneGauge, a portfolio-grade Python web app that turns a
  polygenic-style weighted-sum scoring pattern into a one-click
  layman-friendly product** - plain-English results, a deterministic
  simulated reference population, and a calm, muted UI that never
  leaks jargon on the main screens.

* **Designed and built the full stack end-to-end** - FastAPI backend,
  pure-Python scoring engine with numpy, server-rendered Jinja2
  templates, strict Pydantic v2 input validation, a small JSON API, and
  50 pytest cases covering scoring math, data loading, API contracts,
  and security middleware (100% passing).

* **Treated security as first-class** - documented threat model,
  self-run red-team pass with 24 attack attempts (path traversal, XSS,
  oversized / deeply nested payloads, host-header spoofing,
  type-coercion via Booleans, dependency CVE sweep), resulting in a
  pinned dependency set with zero known vulnerabilities and tight
  response headers (CSP with per-request nonce, XFO, XCTO, COOP, CORP,
  Permissions-Policy).
